### 💻 Sobre mim

Olá! Sou **Ricardo Alves**, Desenvolvedor Full-Stack e bacharel em Ciência da Computação, a viver em Mangualde, Portugal 🇵🇹. Construo aplicações web do banco de dados à interface, com foco em código organizado, desempenho e boa experiência do usuário.

- 🚀 Criei sozinho o **APF**, uma aplicação com ~60 mil linhas usada ao vivo por uma comunidade
- 💼 Freelancer na **NoBuggy**, desenvolvendo aplicações web e landing pages para clientes
- 🔭 Trabalhando com **Next.js, React, TypeScript e PostgreSQL**
- 🌱 Aprofundando em arquitetura de aplicações e back-end
- 🤖 Uso **IA** (Claude, GitHub Copilot, ChatGPT) no dia a dia para ganhar produtividade
- 📫 Aberto a oportunidades como **Desenvolvedor Front-End ou Full-Stack**
